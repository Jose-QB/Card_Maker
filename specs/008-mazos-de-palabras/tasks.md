# Tareas — Mazos de palabras

Cada tarea debe ejecutarse en orden, con pruebas antes del código y sin mezclar
tareas no relacionadas.

- [ ] T1. Añadir contratos de modelo y validación para listas, conceptos,
  palabras, dimensiones y palabras por carta.
- [ ] T2. Añadir pruebas de detección y resaltado de palabras repetidas,
  conservando ocurrencias y asociaciones de concepto.
- [ ] T3. Implementar la validación y normalización pura de entradas de palabras.
- [ ] T4. Añadir pruebas de distribución aleatoria controlada, cálculo de número
  de cartas y combinación prioritaria de conceptos distintos.
- [ ] T5. Implementar la distribución pura, el relleno equilibrado de la última
  carta y la regeneración sin mutar la configuración.
- [ ] T6. Añadir pruebas de cartas con concepto + palabra y de reutilización del
  mismo modelo por preview y PDF.
- [ ] T7. Implementar el estado de mazo de palabras y sus controles de edición en
  componentes accesibles.
- [ ] T8. Añadir las pestañas de imágenes y palabras, dejando imágenes como vista
  inicial y aislando ambas configuraciones.
- [ ] T9. Integrar las cartas de palabras en preview y exportación PDF, incluido
  el reverso general de plancha.
- [ ] T10. Añadir pruebas de contratos de accesibilidad, errores visibles,
  privacidad local y compatibilidad con el flujo de imágenes existente.
- [ ] T11. Ejecutar `npm run check` dentro del harness autorizado y corregir
  cualquier fallo sin declarar éxito si el harness no está disponible.
- [ ] T12. Recorrer cada RF, ejecutar revisión del reviewer y realizar la pasada
  manual en navegador; dejar pendientes visuales explícitos.
- [ ] T13. Añadir pruebas de contrato para que el modo palabras no renderice
  listado ni carrusel de cartas generadas y conserve la previsualización.
- [ ] T14. Reorganizar el menú del modo palabras por tipo, dimensiones, cantidad,
  listas y generación, manteniendo teclado, labels y errores accesibles.
- [ ] T15. Mejorar el diseño visual de cartas de palabras en preview y PDF, con
  jerarquía de concepto, palabra y separación de entradas.
- [ ] T16. Verificar manualmente en navegador el cambio visual, paginación,
  reverso general y ausencia del listado de cartas; documentar pendientes.
- [ ] T17. Añadir pruebas y soporte de color hexadecimal por concepto, incluyendo
  valor por defecto y asociación con cada palabra.
- [ ] T18. Añadir el selector de color al editor y aplicar el resaltado en preview
  y PDF; revisar contraste y accesibilidad visual.
- [ ] T19. Añadir pruebas del parser CSV, plantilla, títulos de columnas, celdas
  vacías, comillas, archivos sin palabras y errores sin mutación.
- [ ] T20. Implementar descarga de plantilla e importación local CSV en el editor
  de listas, conservando la configuración previa cuando falle.
